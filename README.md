# Awesome Open Games [![Awesome](https://awesome.re/badge.svg)](https://awesome.re) [![CC0](https://img.shields.io/badge/license-CC0--1.0-lightgrey.svg)](LICENSE) [![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](CONTRIBUTING.md)

> A curated list of **open source games** you can actually play, plus the **engines, frameworks, tutorials and free assets** you need to build your own.

Open source here means the code is published under an OSI-approved (or otherwise libre) license.
A few *engine remakes* need the original commercial game assets to run — those are marked with 🧩.
License tags are indicative only; always check the repo's `LICENSE` file.

## Strategy (RTS / TBS / 4X)

- [0 A.D.](https://github.com/0ad/0ad) — Historical RTS in the spirit of Age of Empires. `C++` `GPL-2.0 / CC-BY-SA`
- [OpenRA](https://github.com/OpenRA/OpenRA) — Modern engine for classic Command & Conquer–style RTS. `C#` `GPL-3.0`
- [Beyond All Reason](https://github.com/beyond-all-reason/Beyond-All-Reason) — Fast-paced open source RTS (Spring engine family). `Lua` `GPL-2.0`
- [Warzone 2100](https://github.com/Warzone2100/warzone2100) — Classic 3D RTS with a full campaign, liberated in 2004. `C++` `GPL-2.0`
- [Zero-K](https://github.com/ZeroK-RTS/Zero-K) — Spring-engine RTS with physics and terraforming. `Lua` `GPL-2.0`
- [Battle for Wesnoth](https://github.com/wesnoth/wesnoth) — Turn-based fantasy strategy with a huge campaign collection. `C++` `GPL-2.0`
- [FreeCiv](https://github.com/freeciv/freeciv) — Civilization-style turn-based empire builder. `C` `GPL-2.0`
- [TripleA](https://github.com/triplea-game/triplea) — Axis & Allies–style board strategy, online multiplayer. `Java` `GPL-3.0`
- [FreeOrion](https://github.com/freeorion/freeorion) — Master of Orion–inspired space 4X. `C++` `GPL-2.0 / CC-BY-SA`
- [Widelands](https://github.com/widelands/widelands) — Settlers-style slow-paced build-up strategy. `C++` `GPL-2.0`

## Game Engines

Full-featured engines for 2D/3D games.

- [Godot](https://github.com/godotengine/godot) — The flagship open source engine: 2D + 3D, MIT licensed. `C++` `MIT`
- [Bevy](https://github.com/bevyengine/bevy) — Data-driven ECS engine in Rust. `Rust` `MIT / Apache-2.0`
- [O3DE (Open 3D Engine)](https://github.com/o3de/o3de) — AAA-style 3D engine, ex-Lumberyard, Linux-friendly. `C++` `Apache-2.0`
- [Stride](https://github.com/stride3d/stride) — Cross-platform C# engine (ex-Xenko). `C#` `MIT`
- [Urho3D](https://github.com/urho3d/Urho3D) — Lightweight, embeddable game engine. `C++` `MIT`
- [OGRE](https://github.com/OGRECave/ogre) — Veteran 3D rendering engine. `C++` `MIT`
- [Panda3D](https://github.com/panda3d/panda3d) — Disney/CMU engine, great with Python. `C++`/`Python` `BSD`
- [jMonkeyEngine](https://github.com/jMonkeyEngine/jmonkeyengine) — Java 3D engine for beginners and indies. `Java` `BSD-3-Clause`
- [GDevelop](https://github.com/4ian/GDevelop) — No-code 2D/3D engine, exports to web + mobile. `JavaScript` `MIT`
- [Fyrox](https://github.com/FyroxEngine/Fyrox) — Feature-rich 2D/3D engine in Rust with editor. `Rust` `MIT`

## Frameworks & Libraries

Lighter-weight frameworks and rendering libraries.

- [raylib](https://github.com/raysan5/raylib) — Simple, fun C library for learning games programming. `C` `zlib`
- [LÖVE](https://github.com/love2d/love) — 2D framework in Lua, a game-jam favorite. `C++` `zlib`
- [MonoGame](https://github.com/MonoGame/MonoGame) — XNA successor for C# cross-platform games. `C#` `MS-PL`
- [FNA](https://github.com/FNA-XNA/FNA) — Accurate XNA reimplementation for porting classics. `C#` `MS-PL`
- [libGDX](https://github.com/libgdx/libgdx) — Java framework for desktop/Android/iOS/HTML5. `Java` `Apache-2.0`
- [Cocos2d-x](https://github.com/cocos2d/cocos2d-x) — Mature C++ mobile 2D framework. `C++` `MIT`
- [Phaser](https://github.com/phaserjs/phaser) — The standard HTML5 2D game framework. `JavaScript` `MIT`
- [Excalibur](https://github.com/excaliburjs/Excalibur) — TypeScript 2D engine with a friendly API. `TypeScript` `BSD-2-Clause`
- [Kaboom](https://github.com/replit/kaboom) — Fun, beginner-friendly JS game library. `TypeScript` `MIT`
- [HaxeFlixel](https://github.com/HaxeFlixel/flixel) — Haxe 2D engine for retro-style games. `Haxe` `MIT`
- [Flame](https://github.com/flame-engine/flame) — 2D game engine on top of Flutter. `Dart` `MIT`
- [Macroquad](https://github.com/not-fl3/macroquad) — Minimal Rust game library, zero setup. `Rust` `MIT / Apache-2.0`
- [Pygame](https://github.com/pygame/pygame) — Classic Python game library (SDL bindings). `C`/`Python` `LGPL-2.1`
- [Arcade](https://github.com/pythonarcade/arcade) — Modern Python 2D library for teaching. `Python` `MIT`
- [Three.js](https://github.com/mrdoob/three.js) — The WebGL 3D library behind many browser games. `JavaScript` `MIT`
- [Babylon.js](https://github.com/BabylonJS/Babylon.js) — Full web game engine with editor + physics. `TypeScript` `Apache-2.0`
- [PlayCanvas](https://github.com/playcanvas/engine) — WebGL engine with collaborative online editor. `JavaScript` `MIT`

## Free Assets

Art, sound and fonts under libre terms (CC0 / CC-BY / CC-BY-SA / OFL). Always double-check the license of the exact pack you download.

### Art & Sprites

- [Kenney](https://kenney.nl/assets) — Thousands of consistent CC0 game sprites, tiles, UI and 3D models. 🌐 `CC0`
- [OpenGameArt](https://opengameart.org/) — Community pixel art, sprites, textures and 3D models. 🌐 `Mixed libre`
- [itch.io free game assets](https://itch.io/game-assets/free) — Indie asset packs, many CC0. 🌐 `Mixed`

### Audio & Music

- [Freesound](https://freesound.org/) — Huge collaborative SFX database (filter by CC0/CC-BY). 🌐 `Mixed libre`
- [Incompetech](https://incompetech.com/) — Kevin MacLeod's royalty-free music (CC-BY). 🌐 `CC-BY`
- [OpenGameArt audio](https://opengameart.org/art-search-advanced?keys=&field_art_type_tid%5B%5D=13) — Music + SFX with libre licenses. 🌐 `Mixed libre`

### Fonts

- [Google Fonts](https://fonts.google.com/) — Free fonts, mostly SIL Open Font License — great for game UI. 🌐 `OFL`
- [Open Font Library](https://fontlibrary.org/) — Libre fonts only. 🌐 `OFL / libre`

### Asset Tools

- [Blender](https://github.com/blender/blender) — 3D modeling, sculpting, animation, video editing. `C/C++` `GPL`
- [Tiled](https://github.com/mapeditor/tiled) — The standard 2D level/tile-map editor. `C++` `GPL-2.0`
- [Audacity](https://github.com/audacity/audacity) — Record and edit game audio/SFX. `C++` `GPL`

## Dev Tools & Libraries

Low-level building blocks most engines and games share.

- [SDL](https://github.com/libsdl-org/SDL) — Cross-platform window, input, audio and GPU layer. `C` `zlib`
- [SFML](https://github.com/SFML/SFML) — Friendly C++ multimedia library. `C++` `zlib`
- [GLFW](https://github.com/glfw/glfw) — Lightweight OpenGL/Vulkan windowing + input. `C` `zlib`
- [Dear ImGui](https://github.com/ocornut/imgui) — Immediate-mode GUI for tools and debug overlays. `C++` `MIT`
